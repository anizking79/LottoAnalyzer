# 로또 6/45 데이터 분석기 V3 (PWA)

## 가장 쉬운 사용
1. 이 폴더의 `index.html`을 PC 브라우저에서 열어 테스트합니다.
2. GitHub Pages에 올리면 휴대폰/태블릿에서 주소로 접속할 수 있습니다.
3. 지원 브라우저에서는 '홈 화면에 설치' 버튼으로 앱처럼 설치할 수 있습니다.

## GitHub Pages 무료 배포
1. GitHub에서 새 Public 저장소를 만듭니다. 예: `lotto-analyzer`
2. 이 폴더 안의 파일 4개(index.html, manifest.webmanifest, sw.js, icon.svg)를 저장소 최상단에 업로드합니다.
3. GitHub 저장소의 Settings → Pages로 이동합니다.
4. Build and deployment에서 `Deploy from a branch` 선택
5. Branch를 `main`, 폴더를 `/ (root)`로 선택하고 Save
6. 잠시 뒤 `https://사용자명.github.io/lotto-analyzer/` 형태의 주소가 생성됩니다.

## 태블릿/휴대폰
- Android/갤럭시탭: Chrome/Edge에서 사이트를 연 뒤 설치 가능
- iPhone/iPad: Safari 공유 메뉴 → '홈 화면에 추가'
- 첫 온라인 데이터 갱신 후에는 회차 데이터가 기기에 저장됩니다.
- 앱 화면 자체는 오프라인에서도 열리며, 최신 데이터 갱신만 인터넷이 필요합니다.

## 주의
이 도구는 과거 통계로 조합을 점수화할 뿐 실제 추첨 확률을 높인다는 보장은 없습니다.
